# saudi-legal — مهارة قانونية سعودية لـ Claude

مهارة (Skill) تجعل Claude يعمل كمستشار نظامي سعودي **قانوني بحت**: يكيّف الواقعة، ويستشهد برقم المادة ونصّها الحرفي من المصدر الرسمي، ثم يبسّط معناها ويبني عليها الحكم في الواقعة، مع حالة المادة (سارية / معدّلة / ملغاة) والجهة المختصة والمواعيد.

## مصادر الحكم — ثلاث مراتب

| المرتبة | المصدر |
|---|---|
| ١ — النص | النظام ولائحته من هيئة الخبراء بمجلس الوزراء، أم القرى، والجهة المصدِرة |
| ٢ — القضاء | المبادئ والسوابق المنشورة: وزارة العدل، المحكمة العليا، ديوان المظالم، اللجان شبه القضائية |
| ٣ — الشروح والبحوث القضائية | المكتبة القضائية لجمعية «قضاء» ومجلتها المحكّمة، ومجلات وزارة العدل وديوان المظالم |

لا يُقدَّم شرح على سابقة ولا سابقة على نص، وما عدا هذه الثلاث لا يُستشهد به.

## ما فيها

- `SKILL.md` — المنهج: النص ← يعني ببساطة ← وفي حالتك، ودرجات اليقين (أ/ب/ج)، وقسم «ما يلزم التحقق منه».
- `scripts/boe.py` — يجلب نص أي مادة من موقع هيئة الخبراء (`laws.boe.gov.sa`) مع حالتها وكل تعديلاتها، ويبحث داخل النظام.
- `scripts/maktaba.py` — يبحث في فهرس المكتبة القضائية لجمعية «قضاء» وينزّل البحث المطلوب.
- `references/` — خريطة الأنظمة، فهرس 517 وثيقة نظامية، المصادر الرسمية، السوابق، الشروح، وأبواب: المدني، التجاري، العمل، الأحوال الشخصية، الإداري، الجزائي، الإجراءات، القطاعات، والقوالب.

## تنبيهات

- المهارة أداة بحث وصياغة، **وليست استشارة قانونية ولا تغني عن محامٍ مرخّص**.
- الفهارس لقطة بتاريخ إعدادها (15/11/2026م)؛ الأنظمة تُعدَّل، والمهارة مأمورة بفتح النص من مصدره قبل الاستشهاد.
- أداة `boe.py` تجلب نظاماً واحداً في كل مرة وتخزّنه أسبوعاً؛ موقع هيئة الخبراء يحجب الطلبات الآلية المتتابعة.
- نصوص الأنظمة ملك لمصادرها الرسمية، والبحوث ملك لأصحابها؛ المهارة تفهرس وتُحيل ولا تعيد نشر المحتوى.
